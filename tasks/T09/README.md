# T09《责任选择》数字化测评

## 运行

在本目录启动任意静态服务器，例如 `npx serve .`，然后打开浏览器访问显示的地址。若直接双击 `index.html`，部分浏览器可能限制本地视频播放。

## 数据结构

每个情境保存 `understanding_check`、`action_choice`、`reason_choice`、`reaction_time`、`hint_used:false`；每次选择的反应时长按字段保存为毫秒。理解检查不计入情境分数。A/B 均通过理解检查时，行动和理由分数分别按 0/1/2 计分，情境分为二者均值，T09 总分为 A/B 情境分均值；任一情境理解失败则该情境为 `INV`，不直接记 0 分。

## 测试流程

依次检查任务说明、A 导入、A 诱导、A 归属检查、A 行动、A 理由、A 结束、B 导入、B 两项理解检查、B 行动、B 理由、B 结束。开始页仅显示纯色背景和“开始任务”。连续视频使用双层预加载与淡入衔接。选项页不额外重复问题，直接显示素材包原始交互帧；三选项按横向 1×3、四选项按 2×2 识别。系统依次播放每个选项音频，并同步放大对应素材区域；全部朗读完才开放点击。每个选项只可点击一次，无正确/错误提示。完成后点击“下载数据”检查 JSON。
