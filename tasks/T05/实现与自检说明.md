# T05 实现与自检说明

## 1. T05A 流程截图说明

`T05A-连续流程截图.png` 展示使用原始素材播放的原因题节点。首页点击一次“开始任务”后，说明、故事、情绪题和原因题自动衔接。儿童直接点击画面内图片，也可选择“不知道”；不采集口语。

流程：任务说明 → 气球故事 → 情绪判断 → 原因判断 → T05A 结束。情绪与原因分别生成一条记录，并在 T05A 内计算均分。

## 2. T05B 流程截图说明

`T05B-流程截图.png` 展示小熊回到两个盒子前后的错误信念位置题。蓝盒、黄盒均保持可点击且不突出真实位置。

流程：初始位置 → 小熊离场 → 小猴移动贴纸 → 小熊返回 → 寻找位置 → 理由 → 记忆控制 → 现实控制 → 结束。两道控制题均实现、均保存、均不进入能力分。

情境 B 素材对应关系：

- B01–B03：`T05B-010203` 视频与音频。
- B04–B05：`T05B-0405` 视频与音频，结束后停留在蓝盒/黄盒图片选择。
- B06：使用提供的 4:3 三张理由卡原图及 `T05B-06` 音频，完整等比显示，不裁切、不叠加重复题目文字。
- B07：使用提供的记忆控制题静止帧及 `T05B-07` 音频。
- B08：使用提供的现实控制题静止帧及 `T05B-08` 音频。
- B09：`T05B-09` 视频与音频。

## 3. 数据字段

每次回答：

- `participant_id`
- `task`（固定 `T05`）
- `subtask`（`T05A` / `T05B`）
- `trial`
- `question`
- `answer`
- `answer_channel`（`click` / `unknown`）
- `reaction_time`（毫秒）
- `hint_level`（P0 / P1 / P2 / P3）
- `score`
- `validity`
- `timestamp`

T05B 报告额外保存：`memory_control`、`reality_control`。最终报告固定写入 `combined_score: null`，防止误合并。

## 4. 计分逻辑

- T05A 情绪：P0/P1 正确为 2；P2 正确为 1；其余为 0。
- T05A 原因：规则同上。
- T05A 得分：`mean(情绪分, 原因分)`。
- T05B：P0/P1 下位置与理由均正确为 2；仅一项正确为 1；P2 后两项均正确最高为 1；均错误为 0。
- 记忆控制题、现实控制题不计能力分；任一失败或施测无效时，T05B 标记 `INV`，得分为 `null`。
- T05A 与 T05B 独立保存、独立计分、独立报告，不生成 T05 总分。

## 已知环境说明

本交付为无需安装依赖的本地静态 Demo。有声媒体受浏览器自动播放策略限制，因此首页保留一次明确的“开始任务”操作；此后连续播放无需额外操作。
